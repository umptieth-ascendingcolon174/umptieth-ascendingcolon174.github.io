## ✨ Main features

GrabLine offers many tools to help you manage data.

### Parallel downloads
The software breaks large files into smaller parts. It downloads these parts at the same time. This process increases your total speed.

### File resumption
Did your internet connection drop? GrabLine remembers your progress. You can pause or resume any file at your convenience. You save time by not starting over.

### Torrent support
You can manage peer-to-peer transfers inside the app. It uses the Libtorrent library to maintain fast connections. The interface shows your upload and download rates.

### Media selection
The tool integrates with your browser. It identifies video and audio links automatically. You choose the quality and format for each clip. It supports high-definition streams and common audio file types.

### Cloud links
Add your cloud storage URLs directly into the queue. The software fetches these files in the background.
